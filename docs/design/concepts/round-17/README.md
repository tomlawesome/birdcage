# Round 17: sign-in, bars with an unruly trace

One page, one change from round 16.

- **AM, bars, unruly trace** (`direction-am-bars-chaos.html`). The trace
  behind a pulse is bigger and less regular. Most spikes are small; a few
  reach up to 62px and cross the neighbouring bars. The two bars either
  side pick up a fainter trace of their own in the pulse's colour, a
  moment later. The trace flickers while it lasts. Pulses arrive at uneven
  intervals. The bar next to an amber post never reaches past the post, so
  nothing enters the form's space.

`bars.js` draws the bars; `?t=N` draws the scene N seconds in.
`node shot.mjs` retakes `shots/` from the design host.
